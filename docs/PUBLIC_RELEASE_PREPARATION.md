# 公开源码与内测交付边界

原开发仓库含商业摘录、真实Prompt及私有验收资料，部分已经进入Git历史。.gitignore只防止新追踪，不能清除已有文件和历史。本轮不删历史、不改写历史、不推送、不创建公开Release。

## 准备公开源码

```bash
npm run release:audit
npm run release:source
```

audit只读检查已追踪路径及可达历史，检查当前.env实际密钥命中，报告疑似Key/私钥；不打印密钥。它不是完备秘密检测器，范围和未扫描对象会注明。

source默认创建新目录storage/public-source-v1（已有则拒绝覆盖），也可用`npm run release:source -- ../自选新目录`指定输出。快照保留完整应用代码、必要配置、24个Prisma迁移、安装脚本及公开安装测试，排除.git、.env、数据库、storage、日志、商业资料、真实Prompt、旧验收记录和商业测试夹具。旧基准工具不属于公开安装必需项。

公开时应从这个快照另建Git仓库和初始提交，不复制原.git，不直接推原仓库历史，也不强制添加忽略文件。脚本不会自动创建或推送GitHub仓库；原开发仓库和未提交改动保留。

Agent代码中少量剧本专属审核说明已移为随合法资源包安装的私有数据；原有判断逻辑保持。公开源码不带这些剧情文字，也不带完整商业评测集。

## 发布前尚需确认

- 维护者选定源码许可证并加入LICENSE，目前不能宣称已完成标准开源授权。
- 商业资源包的内测提供方式与许可另行确认，不能并入源码仓库。
- 复核安全审计的疑似凭据和未扫描对象；新快照干净不代表旧历史安全。
- Windows实机安装，以及用户自行执行的真实API体验验证。
- 发布收尾已定向升级Next/@next/env至15.5.28、Sharp至0.35.5；生产审计从9项（含1 critical）变为8项（7 high、1 moderate、0 critical）。剩余条件、版本与不跨大版本升级的原因见[发布收尾核对](PUBLIC_RELEASE_FINAL_CHECK.md)，不应将其视为零风险证明。

当前交付为本机小范围内测，不是公网多租户服务。
